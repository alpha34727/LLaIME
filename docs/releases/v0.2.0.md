## 新功能

- **參考後文選字**：在句子中間插入文字時，大語言模型會參考游標後面的文字來選字。設定頁可分開設定參考的前文與後文字數，後文預設 8 字，設為 0 即關閉。立法院、新聞稿、維基評測集上進步 0.3～1.0 個百分點（`tests/eval/RESULTS.md`）。
- **檢查更新**：設定 →「關於」→「檢查更新」，從 GitHub 下載新版安裝檔、核對 SHA-256 後安裝。只有按下按鈕時才會連網。

## 注意

- 本版改變了輸入法與選字引擎之間的通訊格式。安裝後，已經開著的應用程式要重新開啟，才能恢復模型選字。
- 這個安裝檔不含教育部《重編國語辭典修訂本》詞庫，也沒有程式碼簽章；Windows SmartScreen 可能顯示警告，請按「其他資訊」→「仍要執行」。
