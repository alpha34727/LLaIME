## 新功能：LLM 寫字

- 設定 →「選字模型與加速」→「**LLM 寫字比重**」：由大語言模型直接寫出符合注音的句子，而不只是從詞庫組出的 16 句候選中挑選。詞庫的候選常常根本沒有正確的句子（新聞稿約 16%、百科式文字約 22%），讓模型自己寫就不受這個限制。
- 0%（預設）與原本的選字方式相同；往右調，詞庫的影響隨之減少；**50% 在測試中最準**；100% 只看模型。
- 2B 模型、50%：立法院發言 89.6% → 93.4%、新聞稿 80.6% → 87.4%、維基 73.2% → 82.2%；短輸入與日常口語持平。逐字輸入時每打一個音約 13～19 ms（RTX 5060 Ti），比原本的方式更快。
- 選過的候選字、標點、學習記錄都照常保留與套用。使用決策模型（Laya）時這個設定不起作用。

## 注意

- 本版改變了輸入法與選字引擎之間的通訊格式。安裝後，已經開著的應用程式要重新開啟，才能恢復模型選字。
- 這個安裝檔不含教育部《重編國語辭典修訂本》詞庫，也沒有程式碼簽章；Windows SmartScreen 可能顯示警告，請按「其他資訊」→「仍要執行」。
- 0.2.0 以上可在設定 →「關於」→「檢查更新」直接更新。
